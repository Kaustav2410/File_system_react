# File System Visualizer

A React-based file system tree viewer with interactive folder expansion and collapsing.

## Features

### Version 1
- Basic file system visualization using nested JSON structure
- Displays folders and files in a hierarchical view
- Data sourced from `fileStructure.js`

### Version 2
- **Tree Structure UI** — Formatted as a visual file tree with indentation
- **Expand/Collapse** — Toggle folders open and closed with arrow icons
- **Remove All Button** — Clear all folders from view
  - *Note:* Data resets on page reload since structure is loaded from `fileStructure.js`
